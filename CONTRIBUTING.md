# Contributing

Use Node.js 24 or newer. Run `npm ci`, `npm run typegen`, `npm run typecheck`,
`npm test`, and `npm run deploy:check` before submitting a pull request.
These checks do not require Cloudflare credentials or call real AI models.

Keep credentials, account identifiers, personal domains, local data and deployment
artifacts out of changes. Include a focused regression test for API behavior changes.
Please describe the problem, resulting behavior and validation in your pull request.
